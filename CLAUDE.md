# LectureLab
Local lecture-capture + AI study notes app. FastAPI + vanilla JS + SQLite.
Fully local, no paid APIs: faster-whisper for transcription, Ollama for notes.
- Never commit lecturelab.db, audio files, or recordings.
- Use the local Ollama model at localhost:11434, no API keys anywhere.
- Test in a real browser with Playwright before declaring anything done.
- Commit after each major working feature with a descriptive message.
